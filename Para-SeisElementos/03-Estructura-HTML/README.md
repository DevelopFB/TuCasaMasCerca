# Estructura HTML — Landing Tu Casa +Cerca

Este es el punto de partida sobre el cual hay que aplicar diseño visual y maquetado CSS final.

## Cómo abrirlo

Doble clic en `index.html` (abre en cualquier navegador).

## Qué contiene

- `index.html` — archivo único con toda la landing (HTML + CSS + JS inline).
- `assets/` — imágenes referenciadas desde el HTML (rutas relativas).

## Lo que ya está hecho

- Estructura semántica de las 9 secciones del sitemap (Home, Cómo Funciona, Coldwell Banker, Propiedades, Testimonios, Tasas y Cuotas, FAQ, Contacto, Footer).
- Design tokens CSS alineados al brandbook V2 (colores, tipografías, escala).
- Layout base responsive con grids y flexbox.
- Componentes base (cards, botones, formulario, navegación, footer).
- Tipografías Inter + Poppins desde Google Fonts.

## Lo que esperamos que hagas vos

- Diseño visual definitivo en Figma de las 9 secciones (desktop + mobile), validado con el cliente antes de codear.
- Capa CSS final sobre la estructura existente (refinamiento visual, tipografía, jerarquía, contraste, espaciados).
- Optimización / reemplazo de imágenes y assets.
- Microinteracciones, hovers, transiciones, animaciones donde aporten.
- Responsive tuning fino para mobile, tablet y desktop.
- Iconografía complementaria.
- Conexión de CTAs (botón "Simulá tu crédito" → URL de la webapp, a confirmar).
- Formulario de contacto operativo (envío a mail destino).
- SEO básico (meta tags, Open Graph, sitemap.xml, robots.txt, favicon).
- Embed de Google Analytics 4 + Meta Pixel (snippets provistos por el cliente).
- Deploy final en DonWeb (acceso FTP provisto por el cliente).

## Lo que NO necesitamos que hagas

- Rehacer la estructura HTML desde cero.
- Cambiar el framework (no necesitamos Bootstrap si no aporta — la estructura actual es vanilla CSS con design tokens, perfectamente válida para producción).
- Programar backend, base de datos o panel de administración.
- Construir la webapp / plataforma transaccional (eso es otro proyecto, ya desarrollado).

## Importante

El brandbook V2 (carpeta `02-Brandbook/`) es la referencia de identidad. La paleta y tipografía que verás en este `index.html` ya están alineadas; podés profundizar en su aplicación visual final.
